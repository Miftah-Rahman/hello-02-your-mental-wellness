# Hello-02: Mental Health & Wellness App

Bangladesh's premier mental health and peer support platform. Track moods, practice guided mindfulness, connect with peer listeners, take clinical assessments, and consult verified psychologists.

## Features
- **Anonymous Peer Support Hub (`/support`)**: Connect anonymously with empathetic peer listeners or volunteer to support someone in need.
- **Mood Tracking**: Daily emotional check-ins, streaks, and weekly insights.
- **Guided Breathing Exercises**: Box breathing, 4-7-8, and custom mindfulness patterns.
- **Clinical Assessments**: DASS-42 inspired screening tools.
- **Professional Consultations**: Find and book sessions with verified psychologists.

## Development
```bash
npm install
npm run dev
```
